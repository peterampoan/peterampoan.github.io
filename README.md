# peterampoan.github.io

Personal portfolio of Peter C. Ampo-an — live at **https://peterampoan.github.io**

Plain HTML, CSS and a little JavaScript; no build step. Hosted on GitHub Pages.

```
index.html    page content
styles.css    terminal-style theme
script.js     typing effect + footer year
favicon.svg   tab icon
og-image.png  link preview image
```

To preview locally, serve the folder with any static server and open `index.html`.
